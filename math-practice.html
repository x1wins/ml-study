1. Linear Algebra

Shapes, matrix products, dot products, and norms — the plumbing of every model. Refresher: Linear Algebra guide.

Problem 1 · Shape of a matrix product

A is a (3 × 2) matrix and B is a (2 × 4) matrix. What is the shape of the product A · B? Is the multiplication even valid?

Valid? Yes. For A · B, the inner dimensions must match: (3 × 2) · (2 × 4). Both inner values are 2, so it is valid.

Result shape = the outer dimensions = (3 × 4).

(3 × 2) · (2 × 4) → (3 × 4)

Rule: (m × k) · (k × n) → (m × n).

Problem 2 · Compute a 2×2 by 2×1 matmul

Compute the product below.

[ [1, 2], [3, 4] ] · [ [5], [6] ] = ?

Each output row is a dot product of that row of the matrix with the column vector:

Row 1: (1 · 5) + (2 · 6) = 5 + 12 = 17

Row 2: (3 · 5) + (4 · 6) = 15 + 24 = 39

result = [ [17], [39] ]  (shape 2 × 1)
import numpy as np

A = np.array([[1, 2], [3, 4]])
x = np.array([[5], [6]])
print(A @ x)
# [[17]
#  [39]]

Problem 3 · Dot product of two 3-vectors

Compute the dot product of u = [1, 2, 3] and v = [4, 5, 6].

Multiply element-wise, then sum:

(1 · 4) + (2 · 5) + (3 · 6) = 4 + 10 + 18 = 32

u · v = Σi ui vi = 32
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])
print(np.dot(u, v))  # 32

Problem 4 · L2 norm of [3, 4]

What is the L2 (Euclidean) norm of the vector [3, 4]?

The L2 norm is the square root of the sum of squared components:

‖v‖2 = √(3² + 4²) = √(9 + 16) = √25 = 5

This is the classic 3–4–5 right triangle.

import numpy as np

v = np.array([3, 4])
print(np.linalg.norm(v))  # 5.0

Problem 5 · Is W x + b valid?

W has shape (10 × 3), x has shape (3 × 1), and b has shape (10 × 1). Is the expression W x + b a valid computation, and what is its output shape?

Step 1 — matmul: (10 × 3) · (3 × 1). Inner dims match (3 = 3), so W x is valid and has shape (10 × 1).

Step 2 — add bias: W x is (10 × 1) and b is (10 × 1). Shapes match, so the addition is valid.

W x + b → (10 × 1)  ✓ valid

This is exactly one linear layer of a neural network. See Neural Networks.

2. Derivatives

Slopes and the chain rule — the machinery behind gradient descent. Refresher: Derivatives guide.

Problem 6 · d/dx of x3

Differentiate f(x) = x3.

Use the power rule: d/dx of xn = n · xn−1.

d/dx (x3) = 3x2

Problem 7 · d/dx of (3x + 1)2 (chain rule)

Differentiate f(x) = (3x + 1)2.

Let u = 3x + 1, so f = u2. Chain rule: df/dx = (df/du) · (du/dx).

df/du = 2u = 2(3x + 1)  and  du/dx = 3.

df/dx = 2(3x + 1) · 3 = 6(3x + 1) = 18x + 6

Check by expanding first: (3x + 1)2 = 9x2 + 6x + 1 → derivative = 18x + 6. ✓

Problem 8 · d/dx of e−x2 (chain rule)

Differentiate f(x) = e−x2.

Let u = −x2, so f = eu. Chain rule: df/dx = eu · (du/dx).

du/dx = −2x, and eu = e−x2.

df/dx = −2x · e−x2

Problem 9 · d/dx of ln(x)

Differentiate f(x) = ln(x).

The derivative of the natural log is a standard result:

d/dx (ln x) = 1 / x  (for x > 0)

Problem 10 · Partial ∂f/∂x of x2 + y2

Find the partial derivative of f(x, y) = x2 + y2 with respect to x.

Treat y as a constant. Then y2 is a constant (derivative 0), and d/dx of x2 = 2x.

∂f/∂x = 2x   (similarly ∂f/∂y = 2y)

The full gradient is ∇f = [2x, 2y].

3. Integration

The reverse of differentiation, and the "area under the curve". Refresher: Integration guide.

Problem 11 · Indefinite integral of 2x

Evaluate ∫ 2x dx.

Reverse the power rule: ∫ xn dx = xn+1 / (n + 1) + C.

∫ 2x dx = 2 · (x2 / 2) + C = x2 + C

Check: d/dx (x2 + C) = 2x. ✓

Problem 12 · Indefinite integral of x2

Evaluate ∫ x2 dx.

Add 1 to the exponent and divide by the new exponent:

∫ x2 dx = x3 / 3 + C

Check: d/dx (x3/3) = 3x2/3 = x2. ✓

Problem 13 · Definite integral of x from 0 to 2

Evaluate ∫02 x dx.

Antiderivative of x is x2 / 2. Evaluate at the bounds and subtract:

[ x2/2 ]02 = (22/2) − (02/2) = 4/2 − 0 = 2

Geometric check: the region under y = x from 0 to 2 is a triangle with base 2 and height 2, area = ½ · 2 · 2 = 2. ✓

Problem 14 · What does the definite integral mean?

In one sentence, what does ∫ab f(x) dx represent geometrically?

It is the signed area between the curve y = f(x) and the x-axis, from x = a to x = b. Area above the axis counts as positive, area below counts as negative.

Why it matters in ML: probabilities are areas under density curves, and expected values are integrals (or sums) weighted by probability.

4. Logarithms

Turning products into sums and taming tiny probabilities. Refresher: Logarithms guide.

Problem 15 · Evaluate log2(8)

What is log2(8)?

Ask: "2 raised to what power gives 8?" Since 23 = 8:

log2(8) = 3

Problem 16 · Evaluate ln(e3)

What is ln(e3)?

ln is log base e, and logb(bk) = k. Here b = e and k = 3:

ln(e3) = 3

Problem 17 · Simplify log(a) + log(b)

Rewrite log(a) + log(b) as a single logarithm.

The product rule of logs: adding logs multiplies their arguments.

log(a) + log(b) = log(a · b)

Problem 18 · Why sum log-probabilities?

In ML we often maximize a sum of log-probabilities Σ log(pi) instead of the product ∏ pi. Give the main numerical reason.

Underflow. Multiplying many probabilities (each between 0 and 1) produces a number so tiny it rounds to 0 in floating point, destroying the value.

Taking logs turns the product into a sum: log(∏ pi) = Σ log(pi). The sum stays in a safe numeric range, and log is monotonic so the maximizer is unchanged.

import numpy as np

p = np.full(1000, 0.1)      # 1000 probabilities of 0.1
print(np.prod(p))           # 0.0            (underflowed to zero!)
print(np.sum(np.log(p)))    # -2302.585...   (safe, usable)

5. Probability & Statistics

Means, spread, independence, Bayes, and expected value. Refresher: Probability & Statistics guide.

Problem 19 · Mean and standard deviation

For the list [2, 4, 4, 4, 5, 5, 7, 9], compute the mean and the (population) standard deviation.

Mean = sum / count = (2+4+4+4+5+5+7+9) / 8 = 40 / 8 = 5.

Deviations from the mean: −3, −1, −1, −1, 0, 0, 2, 4.

Squared deviations: 9, 1, 1, 1, 0, 0, 4, 16. Sum = 32.

Variance (population) = 32 / 8 = 4.   Std = √4 = 2.

import numpy as np

data = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(data.mean())  # 5.0
print(data.std())   # 2.0   (population std, ddof=0)

Problem 20 · P(A and B) for independent events

Two independent events have P(A) = 0.5 and P(B) = 0.2. What is P(A and B)?

For independent events, the joint probability is the product:

P(A ∧ B) = P(A) · P(B) = 0.5 · 0.2 = 0.1

(This multiplication rule holds only when the events are independent.)

Problem 21 · Bayes: the surprising test result

A disease affects 1% of people. A test is 99% accurate: it correctly flags 99% of sick people (sensitivity) and correctly clears 99% of healthy people (specificity). You test positive. What is the probability you actually have the disease?

Bayes' theorem: P(D | +) = P(+ | D) · P(D) / P(+).

Numerator (true positives): P(+ | D) · P(D) = 0.99 · 0.01 = 0.0099.

False positives: P(+ | not D) · P(not D) = 0.01 · 0.99 = 0.0099.

Total P(+) = 0.0099 + 0.0099 = 0.0198.

P(D | +) = 0.0099 / 0.0198 = 0.5  (~50%)

Even with a 99% accurate test, a positive result means only about a 50% chance of disease, because the disease is rare and false positives are as numerous as true positives.

prevalence  = 0.01
sensitivity = 0.99   # P(+ | disease)
specificity = 0.99   # P(- | healthy)  ->  P(+ | healthy) = 0.01

tp = sensitivity * prevalence            # 0.0099
fp = (1 - specificity) * (1 - prevalence) # 0.0099
posterior = tp / (tp + fp)
print(round(posterior, 4))  # 0.5

Problem 22 · Expected value of a fair die

What is the expected value of a single roll of a fair six-sided die?

Each face 1–6 has probability 1/6. Expected value = Σ (value · probability):

E[X] = (1 + 2 + 3 + 4 + 5 + 6) / 6 = 21 / 6 = 3.5

The expected value need not be an achievable outcome — you can never roll a 3.5, yet that is the long-run average.

6. Evaluation Metrics

Turning a confusion matrix into precision, recall, and F1. Refresher: Evaluation Metrics guide.

Problem 23 · Precision, recall, and F1

A classifier has TP = 40, FP = 10, FN = 20. Compute precision, recall, and the F1 score.

Precision = TP / (TP + FP) = 40 / (40 + 10) = 40 / 50 = 0.8.

Recall = TP / (TP + FN) = 40 / (40 + 20) = 40 / 60 ≈ 0.667.

F1 = 2 · (precision · recall) / (precision + recall):

F1 = 2 · (0.8 · 0.667) / (0.8 + 0.667) = 1.0672 / 1.4667 ≈ 0.727
tp, fp, fn = 40, 10, 20
precision = tp / (tp + fp)          # 0.8
recall    = tp / (tp + fn)          # 0.6667
f1 = 2 * precision * recall / (precision + recall)
print(round(precision, 3))  # 0.8
print(round(recall, 3))     # 0.667
print(round(f1, 3))         # 0.727

F1 is the harmonic mean of precision and recall — it stays low unless both are high.

7. Softmax by Hand

Turning raw scores (logits) into a probability distribution. Refresher: Activation functions.

Problem 24 · Softmax of [2, 1, 0]

Compute the softmax of the logits [2, 1, 0]. Show the exponentials and the normalization.

Step 1 — exponentiate each logit:

e2 ≈ 7.389,   e1 ≈ 2.718,   e0 = 1.000

Step 2 — sum them: 7.389 + 2.718 + 1.000 = 11.107

Step 3 — divide each by the sum:

7.389 / 11.107 ≈ 0.665
2.718 / 11.107 ≈ 0.245
1.000 / 11.107 ≈ 0.090

softmax([2, 1, 0]) ≈ [0.665, 0.245, 0.090], and the three values sum to 1.000 as required.

import numpy as np

z = np.array([2.0, 1.0, 0.0])
e = np.exp(z - np.max(z))   # subtract max for numerical stability
softmax = e / e.sum()
print(np.round(softmax, 3))  # [0.665 0.245 0.09 ]
Note: subtracting the max before exponentiating (a common trick) does not change the result — it only prevents overflow for large logits.
