🎲 Probability & Statistics for AI

Describe data, model uncertainty, and update beliefs with evidence — the language every machine-learning model speaks, explained simply with runnable code.

← Back to Learning Path
Big picture: ML models don't output certainties — they output probabilities. Statistics tells us how to summarize data (mean, spread), probability tells us how likely things are (0 to 1), and Bayes' theorem tells us how to update a belief when new evidence arrives. Training a model is really just finding the parameters that make the observed data most likely.

1. Descriptive Statistics

Before modelling anything, summarize your data: where is its center, and how spread out is it?

Mean (the average / center)

The mean μ adds up all values and divides by how many there are. It's the balance point of the data.

μ = (1/n) · Σ xi

Variance (how spread out?)

Variance σ2 measures the average squared distance of each value from the mean. Squaring keeps everything positive and punishes big deviations more.

σ2 = (1/n) · Σ (xi − μ)2

Standard deviation (spread in original units)

The standard deviation σ is the square root of the variance. Because we undid the squaring, it's back in the same units as the data — easy to interpret.

σ = √( σ2 ) = √( (1/n) · Σ (xi − μ)2 )

Tiny worked example

Take the data set [2, 4, 4, 4, 5, 5, 7, 9] (n = 8):

StepComputationResult
Mean μ(2+4+4+4+5+5+7+9) / 8 = 40 / 85
Squared diffs9, 1, 1, 1, 0, 0, 4, 16Σ = 32
Variance σ232 / 84
Std dev σ√42
Why it matters: features on wildly different scales confuse many models. Knowing μ and σ lets you standardize data with (x − μ) / σ so every feature is comparable — a routine first step in ML pipelines.

Mean & std in code

import numpy as np

data = np.array([2, 4, 4, 4, 5, 5, 7, 9])

mean = data.mean()          # 5.0
var  = data.var()           # 4.0   (population variance, divides by n)
std  = data.std()           # 2.0   (sqrt of variance)

print(f"mean = {mean}")     # mean = 5.0
print(f"var  = {var}")      # var  = 4.0
print(f"std  = {std}")      # std  = 2.0

# NOTE: use ddof=1 for the *sample* variance (divides by n-1)
print(data.var(ddof=1))     # 4.571...

2. The Normal / Gaussian Distribution

The famous "bell curve" — the most important distribution in statistics and ML.

What is a distribution?

A distribution describes how likely each possible value is. For continuous data we use a probability density function (PDF). The normal (Gaussian) distribution is the symmetric bell shape centered on the mean μ, with width set by the standard deviation σ.

f(x) = (1 / (σ√(2π))) · e−(x − μ)2 / (2σ2)

In the simplest "standard normal" case (μ = 0, σ = 1) the exponent is just −x²/2. The base of that exponential is Euler's number e — see Euler's number.

The bell curve

  • About 68% of values fall within ±1σ of the mean
  • About 95% fall within ±2σ
  • About 99.7% fall within ±3σ
Total area = 1. The area under any PDF is exactly 1, because some value must occur (probabilities sum to 100%). Computing that area is an integration problem — integrating the Gaussian over all x gives 1.

Gaussian PDF in code

import numpy as np

def gaussian_pdf(x, mu=0.0, sigma=1.0):
    coeff = 1.0 / (sigma * np.sqrt(2 * np.pi))
    exponent = -((x - mu) ** 2) / (2 * sigma ** 2)
    return coeff * np.exp(exponent)

# Peak of the standard normal is at x = mu = 0
print(gaussian_pdf(0.0))     # 0.3989422804014327  == 1/sqrt(2*pi)
print(gaussian_pdf(1.0))     # 0.24197072451914337 (one std out)
print(gaussian_pdf(-1.0))    # 0.24197072451914337 (symmetric)

# The curve is symmetric, so f(1) == f(-1)
assert np.isclose(gaussian_pdf(1.0), gaussian_pdf(-1.0))

The peak value 1/√(2π) ≈ 0.3989 confirms the formula is correct for the standard normal.

3. Probability Basics

Probability is a number from 0 (impossible) to 1 (certain) that measures how likely an event is.

The three rules you always need

RuleMeaningFormula
Range Every probability is between 0 and 1 0 ≤ P(A) ≤ 1
Complement The chance an event does not happen P(not A) = 1 − P(A)
Independence Two events that don't affect each other: multiply P(A and B) = P(A) × P(B)
Why it matters: a classifier that says "90% cat" is stating P(cat) = 0.9, which automatically means P(not cat) = 0.1. The independence rule is the whole idea behind Naive Bayes (section 8).

Independent events example

Flip a fair coin twice. Each flip is independent with P(heads) = 0.5.

P(two heads) = 0.5 × 0.5 = 0.25

The chance of at least one tails is the complement: 1 − 0.25 = 0.75.

4. Conditional Probability P(A|B)

The probability of A given that B already happened. New information changes the odds.

Definition

P(A|B) reads "the probability of A given B." We narrow the world down to only the cases where B is true, then ask how often A also holds.

P(A|B) = P(A and B) / P(B)
Why it matters: almost everything a model predicts is conditional — a spam filter estimates P(spam | the words in this email), not the raw base rate of spam. Conditioning on evidence is the essence of prediction.

5. Bayes' Theorem

The rule for flipping a conditional around — updating a belief when evidence arrives.

The formula

P(A|B) = ( P(B|A) · P(A) ) / P(B)
  • P(A) — the prior: what we believed before seeing evidence
  • P(B|A) — the likelihood: how well A explains the evidence
  • P(B) — the evidence: total probability of seeing B
  • P(A|B) — the posterior: our updated belief

Worked example: a medical test

A disease affects 1% of people. A test is 99% accurate: it correctly flags 99% of sick people (true positives) and correctly clears 99% of healthy people (so 1% false positives). You test positive. What's the chance you're actually sick?

Imagine 10,000 people. 100 are sick (1%). Of those, 99 test positive. Of the 9,900 healthy people, 1% — that's 99 — also test positive by mistake. So 198 people test positive, but only 99 are truly sick.

P(sick | positive) = 99 / (99 + 99) = 99 / 198 = 0.5

Plugging into Bayes' theorem directly, with A = sick, B = positive:

P(A|B) = (0.99 · 0.01) / (0.99 · 0.01 + 0.01 · 0.99) = 0.0099 / 0.0198 = 0.5
Why it matters: despite a "99% accurate" test, a positive result only means a 50% chance of being sick — because the disease is rare (low prior). This base-rate effect is why models must weigh evidence against how common something is. The identical logic drives Naive Bayes spam filters.

Bayes in code

import numpy as np

p_sick        = 0.01        # prior P(A)
p_pos_if_sick = 0.99        # likelihood P(B|A)
p_pos_if_well = 0.01        # false-positive rate P(B|not A)

# total probability of testing positive P(B)
p_pos = p_pos_if_sick * p_sick + p_pos_if_well * (1 - p_sick)

# posterior P(A|B)
posterior = (p_pos_if_sick * p_sick) / p_pos
print(round(posterior, 4))  # 0.5

6. Expected Value E[X]

The long-run average outcome, weighting each value by how likely it is.

Definition

The expected value is a probability-weighted average: multiply each possible value by its probability, then sum.

E[X] = Σ x · p(x)

Example: a weighted die bet

A game pays you the number rolled on a fair six-sided die. Each face has probability 1/6:

E[X] = (1+2+3+4+5+6) · (1/6) = 21/6 = 3.5
import numpy as np

values = np.array([1, 2, 3, 4, 5, 6])
probs  = np.full(6, 1/6)           # each face equally likely

expected = np.sum(values * probs)  # dot-product style sum
print(expected)                    # 3.5
Why it matters: a loss function is an expected value — the average error over the data distribution. Training minimizes that expectation. See loss functions.

7. Likelihood & Maximum Likelihood

The intuition behind almost all model training: pick the parameters that make your data most probable.

Probability vs. likelihood

Probability: parameters are fixed, we ask how likely some data is. Likelihood: the data is fixed (we observed it), and we ask which parameters best explain it. Maximum likelihood estimation (MLE) chooses the parameters that maximize the probability of the observed data.

θ* = argmaxθ ∏i P(xi | θ)

Why we take the log

Multiplying many small probabilities gives a tiny number that underflows to zero. Taking the log turns the product into a sum, which is stable and easy to differentiate. Because log is monotonic, whatever maximizes the likelihood also maximizes the log-likelihood.

log ∏i P(xi|θ) = Σi log P(xi|θ)
The big connection: minimizing cross-entropy loss is exactly the same as maximizing log-likelihood (with a minus sign in front). That's why classifiers are trained with cross-entropy. See logarithms and loss functions.

Log-likelihood in code

import numpy as np

# Observed coin flips (1 = heads). We want the p that best explains them.
flips = np.array([1, 1, 0, 1, 0, 1, 1, 0, 1, 1])

def log_likelihood(p, data):
    # P(x|p) = p if heads else (1-p); sum the logs
    return np.sum(np.log(np.where(data == 1, p, 1 - p)))

for p in [0.3, 0.5, 0.7, 0.9]:
    print(f"p={p}: log-likelihood={log_likelihood(p, flips):.3f}")

# The MLE for a coin is just the observed head fraction:
p_mle = flips.mean()
print(f"MLE p = {p_mle}")   # 0.7  (7 heads out of 10)

The log-likelihood peaks near p = 0.7, matching the 7-of-10 heads we observed — MLE recovers the intuitive answer.

8. How ML Uses Probability

Everywhere you look

  • Classifiers output probabilities — softmax turns scores into P(class) values that sum to 1
  • Naive Bayes — combines Bayes' theorem with the independence rule (multiply per-feature probabilities) for fast, surprisingly strong text classifiers
  • Uncertainty — a well-calibrated model says "70% sure," letting downstream systems decide when to defer to a human
  • Sampling & temperature — language models draw the next token from a probability distribution; temperature reshapes it (low = confident/repetitive, high = diverse/creative)
  • Evaluation — metrics like precision, recall, and ROC-AUC are built on conditional probabilities. See evaluation metrics
Foundation: the algebra behind all of this — sums, products, vectors and matrices — lives in math foundations, and the exponential curve at the heart of the Gaussian comes from Euler's number.

Quick recap

  • Mean / variance / std — center and spread of data
  • Normal distribution — the bell curve; total area under it is 1
  • Probability — a number in 0…1; complements subtract, independents multiply
  • Bayes' theorem — update a prior belief with new evidence
  • Expected value — probability-weighted average, Σ x·p(x)
  • Maximum likelihood — pick parameters that make the data most probable (↔ cross-entropy)
