1. Intuition — slope and instantaneous rate of change

A derivative answers one question: how fast is this function changing right now?

Slope, but zoomed all the way in

For a straight line, "slope" is rise over run: how much y changes for a step in x. But most functions curve, so their steepness changes from point to point. The derivative gives the slope of the tangent line — the straight line that just kisses the curve at a single point. That slope is the instantaneous rate of change at that point.

average slope = Δy / Δx  →  instantaneous slope = f'(x)
Why it matters: "How steep is this curve here, and in which direction?" is the single question that lets a model know how to change its parameters to reduce error.

2. The limit definition

The formal way to "zoom all the way in" — shrink the run to nothing.

From secant to tangent

Pick a point x and a nearby point x + h. The line through both points (a secant) has slope [f(x + h) − f(x)] / h. As the gap h shrinks toward zero, the secant becomes the tangent, and its slope becomes the derivative:

f'(x) = limh → 0   [ f(x + h) − f(x) ] / h

The notation f'(x) ("f prime of x") and Leibniz's df/dx mean the same thing: the derivative of f with respect to x.

Key idea: a derivative is a limit of average slopes. The → 0 is what turns an average rate of change into an instantaneous one.

Deriving f(x) = x² by hand

Plug f(x) = x² into the definition and expand:

f'(x) = limh → 0 [ (x + h)² − x² ] / h

Expand (x + h)² = x² + 2xh + h², so the numerator becomes 2xh + h². Divide by h to get 2x + h. Now let h → 0:

f'(x) = 2x

This is exactly what the power rule below gives instantly — the rules are just shortcuts for this limit.

3. The differentiation rules

Nobody computes limits by hand every time. These rules do it for you.

The core rules

Constant c 0 f = 7 → f' = 0
Power xn n · xn−1 x³ → 3x²
Constant multiple c · g(x) c · g'(x) 5x² → 10x
Sum g(x) + h(x) g'(x) + h'(x) x² + x → 2x + 1
Product g(x) · h(x) g'·h + g·h' see below
Quotient g(x) / h(x) (g'·h − g·h') / h² see below
Chain g(h(x)) g'(h(x)) · h'(x) see below

The power rule, step by step

Bring the exponent down as a multiplier, then subtract one from the exponent:

xn  →  n · xn−1
  • x² → 2x1 = 2x
  • x³ → 3x²
  • x (which is x1) → 1 · x0 = 1
  • √x = x1/2 → (1/2) · x−1/2

Product rule

The derivative of a product is not the product of the derivatives. Instead:

(g · h)' = g' · h + g · h'

Example: f(x) = x² · sin(x). With g = x² (g' = 2x) and h = sin(x) (h' = cos(x)):

f'(x) = 2x · sin(x) + x² · cos(x)

Quotient rule

(g / h)' = (g' · h − g · h') / h²

Example: f(x) = x / (x + 1). With g = x (g' = 1) and h = x + 1 (h' = 1):

f'(x) = [ 1 · (x + 1) − x · 1 ] / (x + 1)² = 1 / (x + 1)²

Chain rule — the most important one for ML

For a function inside a function (a composition), multiply the outer derivative by the inner derivative:

[ g(h(x)) ]' = g'(h(x)) · h'(x)

Example: f(x) = (3x + 1)². Outer is (·)² with derivative 2(·); inner is 3x + 1 with derivative 3:

f'(x) = 2(3x + 1) · 3 = 6(3x + 1)
Remember this: the chain rule literally is backpropagation. A neural network is one big composition of functions, and backprop applies the chain rule layer by layer. More in section 8.

Why e is special: the number e ≈ 2.71828 is defined precisely so that the curve ex has slope equal to its own height at every point. See Euler's number (e) for the full story.

5. Higher-order derivatives

Differentiate again, and again

The derivative f'(x) is itself a function, so you can differentiate it to get the second derivative f''(x), and again for the third, and so on.

  • First derivative f'(x) — the slope (rate of change)
  • Second derivative f''(x) — the rate of change of the slope (curvature / acceleration)

Example with f(x) = x³:

f(x) = x³ → f'(x) = 3x² → f''(x) = 6x → f'''(x) = 6
Why it matters: if f is position, then f' is velocity and f'' is acceleration. In optimization, the second derivative tells you whether a flat spot is a minimum (curving up) or a maximum (curving down).

6. Partial derivatives & the gradient ∇f

Most ML functions take many inputs. Partial derivatives handle one input at a time.

Partial derivative: hold the others still

When a function has several variables, a partial derivative measures how the output changes as you nudge one variable while treating all other variables as constants. The curly ∂ replaces the straight d.

For f(x, y) = x² + y²:

∂f/∂x = 2x   (y treated as constant, so y² → 0)
∂f/∂y = 2y   (x treated as constant, so x² → 0)
The trick: to compute ∂f/∂x, pretend every other variable is just a fixed number. Its derivative is then 0 (constant rule), so it drops out.

The gradient ∇f: all the partials in one vector

The gradient (written ∇f, "nabla f" or "grad f") collects every partial derivative into a single vector. It points in the direction of steepest increase of the function.

∇f = [ ∂f/∂x , ∂f/∂y ]

So for f(x, y) = x² + y²:

∇f = [ 2x , 2y ]
Why it matters: the gradient is the compass of machine learning. Because ∇f points uphill, moving in the opposite direction (−∇f) takes you downhill toward smaller loss. That single idea is gradient descent.

7. Worked examples

Single variable: f(x) = x²

  1. Apply the power rule to x²: bring the 2 down, drop the exponent by one.
  2. 2 · x2−1 = 2 · x1.
  3. Result: f'(x) = 2x.
f(x) = x²  →  f'(x) = 2x

Check at x = 3: slope is 2 · 3 = 6. The curve is rising steeply there.

Two variables: f(x, y) = x² + y²

  1. ∂f/∂x: treat y as constant → y² is a constant → its derivative is 0 → ∂f/∂x = 2x.
  2. ∂f/∂y: treat x as constant → x² is a constant → its derivative is 0 → ∂f/∂y = 2y.
  3. Stack them into the gradient.
∇f = [ 2x , 2y ]

At the point (x, y) = (3, −1) the gradient is [6, −2]; to reduce f you step along [−6, 2].

8. Why derivatives matter in machine learning

Gradient descent

Training a model means minimizing a loss function — a number that measures how wrong the model is. The gradient of the loss with respect to each parameter tells us which way to nudge that parameter to reduce the loss. We repeat this small downhill step many times:

parameter = parameter − learningRate × ∇loss
Connection: the gradient descent picture in section 6 is exactly what training looks like. See Training & Optimization for learning rates, momentum, and Adam.

Backpropagation is the chain rule

A neural network is a deep composition of functions: layer after layer, each feeding the next. To find how a weight buried deep inside affects the final loss, we apply the chain rule repeatedly, multiplying local derivatives from the output back to that weight. That is precisely backpropagation.

∂L/∂w = (∂L/∂a) · (∂a/∂z) · (∂z/∂w)
The punchline: if you understand the chain rule, you understand the core of backprop. See Neural Networks for the full learning loop.

9. Code: numerical derivative vs. analytic 2x

Estimate a derivative with a tiny finite difference, then compare to the exact answer.

Finite differences with numpy

The limit definition says f'(x) ≈ [f(x + h) − f(x)] / h for small h. A more accurate variant is the central difference [f(x + h) − f(x − h)] / (2h). For f(x) = x² the exact derivative is 2x, so we can measure the error.

import numpy as np

def f(x):
    return x ** 2          # f(x) = x squared

def analytic_deriv(x):
    return 2 * x           # f'(x) = 2x  (power rule)

def numerical_deriv(func, x, h=1e-6):
    # central difference: symmetric, more accurate than forward difference
    return (func(x + h) - func(x - h)) / (2 * h)

# Evaluate at several points at once
xs = np.array([-2.0, 0.0, 1.0, 3.0, 5.0])

approx = numerical_deriv(f, xs)   # numpy broadcasts over the whole array
exact  = analytic_deriv(xs)

print("x        :", xs)
print("numerical:", np.round(approx, 6))
print("analytic :", exact)
print("max error:", np.max(np.abs(approx - exact)))

# Expected output:
# x        : [-2.  0.  1.  3.  5.]
# numerical: [-4.  0.  2.  6. 10.]
# analytic : [-4.  0.  2.  6. 10.]
# max error: ~1e-9  (numerical matches analytic 2x to ~9 decimals)
Takeaway: the finite-difference estimate matches the analytic 2x to about nine decimal places. Numerical derivatives are a great sanity check, but real ML uses automatic differentiation (exact chain-rule gradients) because finite differences are slow and less precise at scale.
