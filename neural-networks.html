🧠 Neural Networks: The Four Building Blocks

Weights, Bias, Activation Functions, and Backpropagation — explained simply, with the "why it matters" and runnable code.

1. The Neuron — the whole idea in one picture

Every neural network is built from one tiny unit repeated thousands of times: the neuron.

What a single neuron does

A neuron takes inputs, multiplies each by a weight, adds them up, adds a bias, then passes the result through an activation function.

output = activation( (w1x1 + w2x2 + … + wnxn) + b )
Why it matters: "Deep learning" is just millions of these neurons stacked in layers. Understand one neuron and you understand the whole network.

2. Weights

The knobs the network turns to learn. Weights decide how important each input is.

What is a weight?

A weight is a number multiplied by an input. A big weight means "this input matters a lot"; a weight near zero means "mostly ignore this input"; a negative weight means "this input pushes the answer the other way".

contribution of an input = weight × input
Why it matters: Learning = finding the right weights. Everything the model "knows" is stored in its weights.

Weights in code

import numpy as np

inputs  = np.array([1.0, 2.0, 3.0])     # x
weights = np.array([0.2, 0.8, -0.5])    # w  (learned during training)

# weighted sum = dot product
weighted_sum = np.dot(weights, inputs)  # 0.2 + 1.6 - 1.5 = 0.3
print(weighted_sum)  # 0.3

A whole layer stores its weights as a matrix, so all neurons compute at once with one matrix multiply.

3. Bias

A shift value that lets a neuron fire even when inputs are zero.

What is a bias?

The bias is an extra number added after the weighted sum. It shifts the result up or down, independent of the inputs. Think of it like the intercept b in the line equation y = mx + b.

z = (w1x1 + … + wnxn) + b
Why it matters: Without a bias, every neuron is forced through the origin (output 0 when all inputs are 0). The bias gives the network freedom to fit data that doesn't pass through zero — greatly increasing what it can learn.

z = np.dot(weights, inputs) + bias   # bias is a single number added on

4. Activation Functions

The "should this neuron fire, and how strongly?" step. It adds non-linearity.

Why do we need them?

Without an activation function, stacking layers is pointless: a chain of weighted sums is still just one big weighted sum (a straight line). Activation functions bend the output so the network can learn curves and complex patterns.

Key idea: weights + bias = a straight line. Activation = the bend that lets many lines combine into any shape.

The common activation functions

NameFormulaOutput rangeUsed for
Sigmoid σ(x) = 1 / (1 + e−x) 0 → 1 Probabilities, binary output
Tanh tanh(x) −1 → 1 Zero-centered hidden layers
ReLU max(0, x) 0 → ∞ Default for hidden layers (fast)
Softmax exi / Σj exj sums to 1 Multi-class output probabilities
Rule of thumb: use ReLU for hidden layers (simple and fast), sigmoid for a single yes/no output, and softmax for choosing one of many classes.

Activation functions in code

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)

def softmax(x):
    e = np.exp(x - np.max(x))     # subtract max for numerical stability
    return e / e.sum()

print(sigmoid(0.3))            # 0.574
print(relu(np.array([-2, 5]))) # [0 5]
print(softmax(np.array([2.0, 1.0, 0.1])))  # [0.659 0.242 0.099]

5. Backpropagation

How the network learns: measure the error, then adjust every weight and bias to reduce it.

The learning loop

  1. Forward pass: feed inputs through the network to get a prediction.
  2. Loss: measure how wrong the prediction is (e.g., (prediction − target)²).
  3. Backward pass: use the chain rule to compute how much each weight/bias contributed to the error (the gradient).
  4. Update: nudge every weight/bias downhill: w = w − lr × gradient.
  5. Repeat thousands of times until the loss is small.
Why "back"-propagation? The error is measured at the output, then pushed backward through the layers. The chain rule lets us split the blame: how much did each weight contribute to the final error?

The chain rule (the engine of backprop)

If error L depends on output ŷ, which depends on the sum z, which depends on weight w, the chain rule multiplies the local slopes together:

∂L/∂w = (∂L/∂ŷ) × (∂ŷ/∂z) × (∂z/∂w)

Each factor is easy on its own; multiplying them gives "how much this one weight affects the total error." Do this for every weight = the full gradient.

One neuron learning, from scratch

import numpy as np

def sigmoid(x):        return 1 / (1 + np.exp(-x))
def sigmoid_deriv(y):  return y * (1 - y)   # y is sigmoid(x) already

# Toy problem: learn to output ~0.9 from a fixed input
x, target = 1.5, 0.9
w, b = 0.0, 0.0        # start untrained
lr = 0.5

for step in range(200):
    # 1) forward pass
    z = w * x + b
    y = sigmoid(z)

    # 2) loss = (y - target)^2
    loss = (y - target) ** 2

    # 3) backward pass (chain rule)
    dL_dy = 2 * (y - target)       # dLoss/dy
    dy_dz = sigmoid_deriv(y)       # dy/dz
    dz_dw = x                      # dz/dw
    dz_db = 1                      # dz/db

    grad_w = dL_dy * dy_dz * dz_dw
    grad_b = dL_dy * dy_dz * dz_db

    # 4) update
    w -= lr * grad_w
    b -= lr * grad_b

    if step % 40 == 0:
        print(f"step {step:3d}: y={y:.4f}  loss={loss:.5f}")

print(f"final prediction: {sigmoid(w*x+b):.4f} (target 0.9)")

Run it: the prediction climbs from 0.5 toward 0.9 as the weight and bias learn. A real network does exactly this for millions of weights at once.

6. Putting It Together

A tiny 2-layer network (forward pass)

Combining all four blocks: weights, bias, activation, chained across two layers.

import numpy as np

def sigmoid(x): return 1 / (1 + np.exp(-x))
def relu(x):    return np.maximum(0, x)

# Input (2 features)
x = np.array([0.5, -1.2])

# Layer 1: 2 inputs -> 3 neurons
W1 = np.array([[ 0.1,  0.4],
               [-0.7,  0.2],
               [ 0.3, -0.5]])   # shape (3, 2): 3 neurons, each with 2 weights
b1 = np.array([0.0, 0.1, -0.2]) # one bias per neuron

# Layer 2: 3 inputs -> 1 output neuron
W2 = np.array([0.6, -0.4, 0.9]) # 3 weights
b2 = 0.05

# Forward pass
z1 = W1 @ x + b1        # weighted sums + bias  (layer 1)
a1 = relu(z1)           # activation            (layer 1)

z2 = W2 @ a1 + b2       # weighted sum + bias   (layer 2)
y  = sigmoid(z2)        # activation            (final probability)

print("hidden layer:", a1)
print("prediction  :", round(float(y), 4))
That's a neural network. Training would wrap this in the backprop loop from section 5, adjusting W1, b1, W2, b2 until predictions match the targets.

Quick recap

  • Weight — how important each input is (multiplied)
  • Bias — a shift that lets neurons fire without input (added)
  • Activation — the bend that adds non-linearity (ReLU / sigmoid / softmax)
  • Backpropagation — chain rule + gradient descent to learn the weights & biases
