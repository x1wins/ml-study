🔧 Tools & Frameworks

The libraries that turn ideas into working models — scikit-learn, PyTorch, TensorFlow/Keras, Hugging Face, and the everyday data toolkit — and how to choose between them.

1. The ML Tool Stack — one picture

Most projects flow left to right: prepare data, then reach for the model library that matches the problem's complexity.

From raw data to large language models

Each layer builds on the one before it. You always start with data tools; how far right you go depends on how hard the problem is.

Why it matters: Don't reach for a giant neural network when a scikit-learn model on clean tabular data would be faster, cheaper, and easier to explain. Match the tool to the problem.

2. scikit-learn — classic machine learning

The go-to library for "traditional" ML on tabular data: regression, classification, clustering, and more.

What it is

scikit-learn (imported as sklearn) gives you dozens of ready algorithms — linear/logistic regression, decision trees, random forests, gradient boosting, k-means, SVMs — behind one clean, consistent API. It runs on the CPU and pairs perfectly with NumPy and Pandas.

When to use it: structured/tabular data (spreadsheets, CSVs), small to medium datasets, and when you want quick, interpretable baselines. It is not for images, audio, or text-heavy deep learning — use PyTorch/TensorFlow for those.

The fit / predict API

Almost every scikit-learn model follows the same three-step pattern. Learn it once and it transfers to every estimator:

model.fit(X, y) → model.predict(Xnew) → model.score(X, y)
  • fit(X, y) — learn patterns from training data
  • predict(X) — make predictions on new data
  • score(X, y) — measure accuracy (or R² for regression)
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# Toy data: 2 features -> binary label
X = np.array([[1.0, 2.0], [1.5, 1.8], [5.0, 8.0],
              [6.0, 9.0], [1.2, 0.5], [7.0, 7.5]])
y = np.array([0, 0, 1, 1, 0, 1])

# Split into train / test
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.34, random_state=42)

# 1) fit  2) predict  3) score
model = LogisticRegression()
model.fit(X_train, y_train)              # learn
preds = model.predict(X_test)            # predict
print("predictions:", preds)
print("accuracy   :", model.score(X_test, y_test))

Swap LogisticRegression for RandomForestClassifier and the rest of the code stays identical — that consistency is scikit-learn's superpower.

3. PyTorch vs TensorFlow / Keras

The two big deep-learning frameworks. Both build and train neural networks on CPUs and GPUs; they differ in feel and ecosystem.

The shared core ideas

  • Tensors — multi-dimensional arrays (like NumPy arrays) that can live on a GPU for speed.
  • Autograd — automatic differentiation: the framework tracks every operation and computes gradients for backpropagation for you, so you never write the chain rule by hand.
  • Optimizers — built-in gradient descent variants (SGD, Adam) that update the weights.
  • GPU acceleration — move tensors to a GPU with one call for massive speedups on large models.
Autograd in plain terms: you write only the forward pass; the framework records it as a graph and walks that graph backward to get every gradient automatically. That is the "backpropagation" step, done for you.

PyTorch vs TensorFlow/Keras — which to pick?

Beginner tip: today most tutorials, courses, and cutting-edge models use PyTorch, and Hugging Face is built around it — a great default to learn first. Keras (now multi-backend) is the friendliest on-ramp if you prefer a simpler API.

A tiny PyTorch example (reference only — needs the torch library)

This shows tensors + autograd in action. It requires installing PyTorch, so treat it as reference, not something to run in a plain NumPy environment.

# reference only: requires `pip install torch`
import torch
import torch.nn as nn

# A tensor with gradient tracking turned on
x = torch.tensor([[0.5, -1.2]])          # shape (1, 2)

# A tiny model: 2 inputs -> 1 output
model = nn.Sequential(
    nn.Linear(2, 4),   # hidden layer
    nn.ReLU(),
    nn.Linear(4, 1),   # output
)

target = torch.tensor([[1.0]])
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.05)

for step in range(100):
    optimizer.zero_grad()      # reset gradients
    pred = model(x)            # forward pass
    loss = loss_fn(pred, target)
    loss.backward()            # autograd computes all gradients
    optimizer.step()           # update the weights

print("final prediction:", model(x).item())
Notice: you never wrote a single derivative. loss.backward() is autograd computing every gradient for you — the whole reason deep-learning frameworks exist.

4. Hugging Face — pretrained models made easy

The home of modern AI models. Instead of training from scratch, you download a model someone else already trained and use it in a few lines.

The Hugging Face ecosystem

  • Transformers — the library that loads and runs thousands of pretrained models (text, vision, audio).
  • Datasets — one-line access to thousands of ready-to-use datasets.
  • Hub — a GitHub-like site hosting models, datasets, and demos you can pull down by name.
  • pipelines — the simplest entry point: pick a task, get a working model instantly.
Why it matters: training a large language model from scratch costs millions. Hugging Face lets you stand on the shoulders of those models — do sentiment analysis, translation, or text generation in three lines instead of three months.

A short pipeline() example (reference only — needs the transformers library)

The pipeline() helper hides all the model-loading and tokenizing details. It downloads a model on first use, so treat this as reference.

# reference only: requires `pip install transformers`
from transformers import pipeline

# 1) sentiment analysis
classifier = pipeline("sentiment-analysis")
print(classifier("I love learning about AI tools!"))
# [{'label': 'POSITIVE', 'score': 0.9998}]

# 2) text generation
generator = pipeline("text-generation", model="distilgpt2")
print(generator("Machine learning is", max_length=20))

# 3) zero-shot classification (no training needed)
zshot = pipeline("zero-shot-classification")
print(zshot("The GPU ran out of memory",
            candidate_labels=["hardware", "cooking", "finance"]))
Notice: no training loop, no weights, no math — just name a task. Under the hood a Transformer model (see Transformers) does the heavy lifting.

5. Supporting Tools

The everyday toolkit that surrounds every ML project — for data, visualization, experimentation, and tracking.

The data & workflow essentials

  • NumPy — the foundation: fast n-dimensional arrays and math. Nearly every other library is built on it.
  • Pandas — tables (DataFrames) for loading, cleaning, and exploring tabular data. Your first stop for any CSV.
  • Matplotlib — plotting: charts, curves, and images to understand your data and results.
  • Jupyter — interactive notebooks that mix code, output, and notes — the standard place to explore and prototype.
  • Weights & Biases (W&B) — experiment tracking: logs your metrics, hyperparameters, and model versions so you can compare training runs over time.
import numpy as np
import pandas as pd

# Pandas loads and summarizes tabular data
df = pd.DataFrame({
    "hours_studied": [1, 2, 3, 4, 5],
    "passed":        [0, 0, 0, 1, 1],
})
print(df.describe())              # quick statistics

# NumPy powers the math underneath
X = df[["hours_studied"]].to_numpy()
print("mean hours:", np.mean(X))
Workflow in practice: load data with Pandas, crunch numbers with NumPy, plot with Matplotlib, all inside a Jupyter notebook — then track your training runs with W&B.
