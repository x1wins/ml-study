1. Sigmoid

Task

Implement sigmoid(x) defined as 1 / (1 + np.exp(-x)). It should squash any real number into the range 0 → 1 and work element-wise on a NumPy array.

σ(x) = 1 ÷ (1 + e−x)

Expected behavior: sigmoid(0) returns 0.5 (the curve's midpoint), large positive inputs approach 1, and large negative inputs approach 0.

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

print(sigmoid(0.0))                       # 0.5
print(np.round(sigmoid(np.array([-2.0, 0.0, 2.0])), 4))
# [0.1192 0.5    0.8808]

2. Sigmoid derivative

Task

Implement the derivative of the sigmoid. The neat trick: if s = sigmoid(x), then the derivative is simply s × (1 − s). Write sigmoid_deriv(s) that takes the already-computed sigmoid value.

σ′(x) = s · (1 − s),   where s = σ(x)

Expected behavior: at x = 0, s = 0.5 so the derivative is 0.5 × 0.5 = 0.25 (the steepest point of the curve).

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(s):
    # s is sigmoid(x) already computed
    return s * (1 - s)

s = sigmoid(0.0)
print(sigmoid_deriv(s))                   # 0.25

3. Softmax (numerically stable)

Task

Implement softmax(v) that turns a vector of scores into probabilities that sum to 1. For numerical stability you must subtract the max before exponentiating, otherwise large inputs overflow np.exp.

softmax(v)i = evi − max(v) ÷ Σj evj − max(v)

Expected behavior: softmax([2, 1, 0]) → [0.665, 0.245, 0.090], and the three values add up to 1.

import numpy as np

def softmax(v):
    v = np.asarray(v, dtype=float)
    e = np.exp(v - np.max(v))     # subtract max for numerical stability
    return e / e.sum()

print(np.round(softmax([2, 1, 0]), 3))    # [0.665 0.245 0.09 ]
print(round(softmax([2, 1, 0]).sum(), 6)) # 1.0 (sums to one)

4. Mean squared error

Task

Implement mse(y_true, y_pred): the average of the squared differences between the truth and the prediction. This is the classic regression loss.

MSE = (1 ÷ n) · Σ (ytrue − ypred)2

Expected behavior: for y_true = [1, 2, 3] and y_pred = [1.1, 1.9, 3.2] the errors are −0.1, 0.1, −0.2, giving MSE = 0.02.

import numpy as np

def mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.mean((y_true - y_pred) ** 2)

print(round(float(mse([1, 2, 3], [1.1, 1.9, 3.2])), 4))   # 0.02

5. Binary cross-entropy

Task

Implement binary_cross_entropy(y, p), the loss for yes/no classification where p is the predicted probability of class 1. Clip p away from exactly 0 and 1 so np.log never sees zero, then average over the batch.

BCE = −(1 ÷ n) · Σ [ y · ln(p) + (1 − y) · ln(1 − p) ]

Expected behavior: for confident, mostly-correct predictions y = [1, 0, 1], p = [0.9, 0.1, 0.8] the loss is small, about 0.1446.

import numpy as np

def binary_cross_entropy(y, p):
    y = np.asarray(y, dtype=float)
    p = np.asarray(p, dtype=float)
    p = np.clip(p, 1e-12, 1 - 1e-12)      # avoid log(0)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

print(round(float(binary_cross_entropy([1, 0, 1], [0.9, 0.1, 0.8])), 4))
# 0.1446

6. Cosine similarity

Task

Implement cosine_similarity(a, b): the dot product divided by the product of the two vectors' norms. It measures the angle between vectors, ignoring their length — the backbone of embedding search.

cos(a, b) = (a · b) ÷ (‖a‖ × ‖b‖)

Expected behavior: parallel vectors like [1, 2, 3] and [2, 4, 6] give 1.0; perpendicular vectors like [1, 0] and [0, 1] give 0.0.

import numpy as np

def cosine_similarity(a, b):
    a = np.asarray(a, dtype=float)
    b = np.asarray(b, dtype=float)
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(round(float(cosine_similarity([1, 2, 3], [2, 4, 6])), 4))   # 1.0
print(round(float(cosine_similarity([1, 0], [0, 1])), 4))         # 0.0

7. Gradient descent on f(x) = x²

Task

Minimize f(x) = x**2 using gradient descent. The gradient is f′(x) = 2x. Start from x0 = 10 and repeatedly step downhill: x = x − lr × 2x. After enough steps x should sit near the minimum at 0.

x ← x − lr · (2x),   f′(x) = 2x

Expected behavior: with lr = 0.1 and 100 steps, x is driven to roughly 2e-09 (essentially 0), where f(x) is minimal.

import numpy as np

def gradient_descent(x0=10.0, lr=0.1, steps=100):
    x = float(x0)
    for _ in range(steps):
        grad = 2 * x            # derivative of x**2
        x = x - lr * grad       # step downhill
    return x

x_min = gradient_descent()
print(x_min)                    # 2.0370359763344878e-09  (~0)
print(round(x_min ** 2, 12))    # 0.0  (f(x) at the minimum)

8. Two-layer forward pass

Task

Implement one forward pass of a tiny network: a ReLU hidden layer followed by a sigmoid output. Compute h = relu(W1 · x + b1), then y = sigmoid(W2 · h + b2). Use @ for the matrix × vector products.

h = relu(W1x + b1)  →  y = σ(W2h + b2)

Expected behavior: with the weights below, the hidden layer is [0, 0, 0.55] (ReLU zeroed two neurons) and the final probability is about 0.633.

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)

def forward(x, W1, b1, W2, b2):
    h = relu(W1 @ x + b1)       # hidden layer
    y = sigmoid(W2 @ h + b2)    # output layer
    return h, y

x  = np.array([0.5, -1.2])
W1 = np.array([[ 0.1,  0.4],
               [-0.7,  0.2],
               [ 0.3, -0.5]])   # (3, 2): 3 hidden neurons
b1 = np.array([0.0, 0.1, -0.2])
W2 = np.array([0.6, -0.4, 0.9]) # (3,): 1 output neuron
b2 = 0.05

h, y = forward(x, W1, b1, W2, b2)
print(np.round(h, 4))            # [0.   0.   0.55]
print(round(float(y), 4))        # 0.633
