3. Common Interview Q&A

Answer out loud first, then click “Show answer” to compare with a concise model answer.

Q1. What is gradient descent, and why the minus sign?

Gradient descent is an optimization algorithm that minimizes a loss function by repeatedly stepping in the direction that reduces the loss fastest. The gradient ∇L points in the direction of steepest increase, so we move in the opposite direction — hence the minus sign in the update rule w = w − lr × ∇L. The learning rate lr scales the step size.

Q2. What is backpropagation?

Backpropagation is the algorithm that computes the gradient of the loss with respect to every weight and bias by applying the chain rule backward through the network. The error is measured at the output, then propagated backward layer by layer: ∂L/∂w = (∂L/∂ŷ) × (∂ŷ/∂z) × (∂z/∂w). Those gradients are then used by gradient descent to update the parameters.

Q3. Explain the bias-variance tradeoff.

Bias is error from overly simple assumptions (underfitting — the model misses real patterns). Variance is error from being too sensitive to the training data (overfitting — the model memorizes noise). Lowering one often raises the other, so the goal is a sweet spot that minimizes total error on unseen data. High bias → more capacity; high variance → more data, regularization, or a simpler model.

Q4. What is overfitting, and how do you prevent it?

Overfitting is when a model fits the training data (including its noise) so closely that it generalizes poorly to new data — low training error but high validation error. Prevent it with: more or augmented data, regularization (L1/L2 penalties), dropout (randomly zeroing activations during training), early stopping (halt when validation loss stops improving), and reducing model complexity.

Q5. Precision vs recall vs F1 — when do you prefer each?

Precision = TP / (TP + FP): of the items flagged positive, how many truly are. Prefer it when false positives are costly (e.g., spam filtering marking real mail as spam). Recall = TP / (TP + FN): of all true positives, how many you caught. Prefer it when false negatives are costly (e.g., disease screening). F1 is the harmonic mean 2 · (P · R) / (P + R) — use it when you need a single balanced score, especially with class imbalance.

Q6. Why does softmax use e (the exponential)?

Softmax is exi / Σj exj. The exponential makes every value positive (so outputs are valid probabilities), amplifies differences so larger logits dominate, and is smooth and differentiable for gradient descent. It also pairs cleanly with cross-entropy loss, giving a simple gradient (prediction − target).

Q7. What is the vanishing gradient problem, and how do LSTMs / ReLU help?

In deep or recurrent networks, gradients are products of many small derivatives. With saturating activations like sigmoid (derivative ≤ 0.25), repeated multiplication drives the gradient toward zero, so early layers barely learn. ReLU has a derivative of 1 for positive inputs, so it does not shrink the gradient. LSTMs use a gated cell state with an additive path, letting gradients flow across many time steps without vanishing.

Q8. How does self-attention (Q/K/V) work?

Each token is projected into a Query, Key, and Value vector. Attention scores are the dot products of one token's Query with every token's Key, scaled by 1/√dk and passed through softmax to get weights. The output is the weighted sum of the Values: Attention(Q,K,V) = softmax(QKT / √dk) · V. This lets each token gather information from every other token, capturing context regardless of distance.

Q9. RAG vs fine-tuning — when do you use each?

RAG (retrieval-augmented generation) fetches relevant documents at query time and feeds them into the prompt. Use it for knowledge that changes often, large or private knowledge bases, and when you need citations — no retraining needed. Fine-tuning updates the model's weights on your data. Use it to teach a specific style, format, or skill, or to reduce prompt length for a fixed task. They combine well: fine-tune for behavior, RAG for fresh facts.

Q10. What is cross-entropy loss?

Cross-entropy measures the distance between the predicted probability distribution and the true labels: L = −Σi yi · log(pi). For classification with one-hot labels it reduces to −log(pcorrect), so confident-and-correct predictions incur near-zero loss while confident-and-wrong predictions are heavily penalized. It pairs naturally with softmax outputs.

Q11. Why split data into train / validation / test?

The training set fits the model's parameters. The validation set tunes hyperparameters and guides choices like early stopping — it must stay separate so those decisions do not leak into the parameters. The test set is touched only once at the end to give an unbiased estimate of real-world performance. Without this separation you cannot tell genuine generalization from memorization.

Q12. What is a learning rate, and what happens if it is too high or too low?

The learning rate scales each gradient-descent step: w = w − lr × ∇L. Too high and the updates overshoot the minimum — the loss oscillates or diverges. Too low and training is very slow and may stall in a poor spot. Common fixes: learning-rate schedules (decay over time), warmup, and adaptive optimizers like Adam.

Q13. What are embeddings?

Embeddings are dense, learned vectors that represent discrete items (words, tokens, users, images) in a continuous space where distance encodes similarity. Semantically related items sit close together, so the model can generalize and do arithmetic like king − man + woman ≈ queen. They power search, recommendations, and the input layer of language models.

Q14. L1 vs L2 regularization?

Both add a penalty on weight size to the loss to curb overfitting. L1 (Lasso) adds λ · Σ|w|; it drives some weights exactly to zero, producing sparse models and doing feature selection. L2 (Ridge / weight decay) adds λ · Σw2; it shrinks weights smoothly toward (but not to) zero, spreading influence across features. Elastic Net combines both.

Q15. What is batch normalization (briefly)?

Batch normalization normalizes a layer's inputs across the mini-batch to have roughly zero mean and unit variance, then applies learnable scale and shift parameters. This stabilizes and speeds up training, allows higher learning rates, reduces sensitivity to initialization, and provides a mild regularizing effect.

Q16. How do you handle class imbalance?

Options include: resampling (oversample the minority, e.g., SMOTE, or undersample the majority), class weights in the loss so minority errors count more, choosing metrics that expose imbalance (precision, recall, F1, PR-AUC rather than raw accuracy), adjusting the decision threshold, and collecting more minority data where possible.
