1. Linear Algebra

The language of data. Everything in ML is stored as numbers in grids.

Scalars, Vectors, Matrices, Tensors

NameWhat it isExample
ScalarA single number5
VectorA list of numbers (1D)[1, 2, 3]
MatrixA grid of numbers (2D)[[1, 2], [3, 4]]
TensorNumbers in 3+ dimensionsAn RGB image (height × width × 3)
Why it matters: A dataset is a matrix (rows = examples, columns = features). An image is a tensor. Neural networks are chains of matrix operations.

Key Operations

  • Addition / scaling: combine or resize vectors
  • Dot product: multiply two vectors → a single number (measures similarity)
  • Matrix multiplication: the core operation inside every neural network layer
  • Transpose: flip rows and columns

Dot product example — the heart of a neuron:

output = (w₁·x₁) + (w₂·x₂) + (w₃·x₃) + bias
import numpy as np

weights = np.array([0.2, 0.8, -0.5])
inputs  = np.array([1.0, 2.0, 3.0])

output = np.dot(weights, inputs)   # 0.2 + 1.6 - 1.5 = 0.3
print(output)  # 0.3

2. Calculus

How models learn. Calculus tells us which direction to adjust to improve.

Derivatives & Gradients

A derivative measures how much the output changes when you nudge the input. A gradient is just a collection of derivatives (one per input variable).

Why it matters: Training a model = reducing "error". The gradient points in the direction where error increases — so we step in the opposite direction to reduce it. This is gradient descent.

Gradient Descent (the learning loop)

new_weight = old_weight − (learning_rate × gradient)
# Minimize f(x) = x^2 by walking downhill
x = 10.0            # starting point
learning_rate = 0.1

for step in range(20):
    gradient = 2 * x        # derivative of x^2
    x = x - learning_rate * gradient
    print(f"step {step}: x = {x:.4f}")

# x slides toward 0, the minimum

This tiny loop is the same idea used to train massive neural networks.

The Chain Rule

Lets us compute gradients through many stacked functions. This is what powers backpropagation — the algorithm that trains deep networks.

Derivatives → Gradient (the key link)

A derivative works on a function of one variable: "if I nudge x, how much does f(x) change?"

f(x) = x² → df/dx = 2x

At x = 3, the derivative is 6: a steep, positive slope — increasing x increases f(x) quickly.

A gradient is the same idea for a function of many variables. You take one partial derivative per variable and collect them into a vector:

f(x, y) = x² + y² → ∇f = [ ∂f/∂x , ∂f/∂y ] = [ 2x , 2y ]
ConceptVariablesResultSymbol
Derivativeonea single number (slope)df/dx
Partial derivativeone of manyslope in one direction∂f/∂x
Gradientalla vector of partials∇f
Partial derivative trick: treat every other variable as a constant. For f(x, y) = x² + y² → ∂f/∂x = 2x (the y² term becomes 0) and ∂f/∂y = 2y (the x² term becomes 0).

The gradient vector points toward the steepest increase. To minimize error we step in the opposite direction — that's the minus sign in gradient descent:

new_weight = old_weight − learning_rate × gradient

Two-variable descent in code

# Minimize f(x, y) = x^2 + y^2  (minimum is at 0, 0)
x, y = 5.0, -3.0
lr = 0.1

for step in range(15):
    grad_x = 2 * x          # partial derivative wrt x
    grad_y = 2 * y          # partial derivative wrt y
    x = x - lr * grad_x     # step downhill in x
    y = y - lr * grad_y     # step downhill in y
    print(f"step {step}: x={x:.3f}, y={y:.3f}")

# both x and y slide toward 0 together

The downhill picture

The gradient at each point (arrow) shows the uphill direction; we move the opposite way, sliding down into the valley (the minimum):

In real ML: a network has millions of weights, so the loss L has millions of partial derivatives: ∇L = [∂L/∂w₁, ∂L/∂w₂, …, ∂L/∂wₙ]. Each partial says "how much does error change if I nudge this one weight?" We nudge every weight downhill at once. The chain rule makes computing all these partials efficient — that's backpropagation.

3. Probability & Statistics

How models handle uncertainty and how we measure them.

Core Statistics

  • Mean: the average value
  • Median: the middle value (robust to outliers)
  • Variance / Std Dev: how spread out the data is
  • Distribution: the shape of your data (e.g., the bell curve / normal distribution)
import numpy as np

data = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print("mean:", data.mean())    # 5.0
print("std :", data.std())     # 2.0

Probability Basics

  • Probability: a number from 0 (never) to 1 (always)
  • Conditional probability: P(A | B) — chance of A given B happened
  • Bayes' Theorem: update beliefs when new evidence arrives
P(A | B) = P(B | A) × P(A) / P(B)
Why it matters: Classifiers output probabilities ("90% cat, 10% dog"). Bayes' theorem is the foundation of spam filters and many classic ML models.

4. Optimization (bonus)

Optimization ties it all together: it's the process of finding the best model parameters by minimizing a loss function (a number measuring how wrong the model is).

  • Loss function: measures error (e.g., Mean Squared Error)
  • Goal: find weights that make loss as small as possible
  • Method: gradient descent (from the calculus section)
MSE = average( (prediction − actual)² )
