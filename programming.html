1. Why Python?

Not the fastest language — but by far the most practical one for machine learning.

What makes Python the ML language

Python reads almost like English, so you spend your time on ideas, not syntax. More importantly, nearly every ML tool in the world has a Python interface.

  • Readable — clean, low-ceremony syntax that beginners can pick up fast
  • Batteries included — huge ecosystem: NumPy, Pandas, scikit-learn, PyTorch, TensorFlow
  • Fast under the hood — the heavy math runs in C/Fortran; Python just orchestrates
  • Community — tutorials, answers, and pre-trained models everywhere
Why it matters: The math you learn in math-foundations.html (vectors, matrices, gradients) maps almost one-to-one onto NumPy code. Python is where the theory becomes something you can run.

2. Python Essentials for ML

You don't need to master all of Python — just a handful of building blocks.

Lists and dictionaries

A list is an ordered collection; a dict maps keys to values. These two structures show up constantly — feature names, label mappings, config settings.

features = ["age", "income", "score"]   # list: ordered
features.append("region")               # add an item
print(features[0])                       # "age"

# dict: key -> value lookups
label_map = {0: "cat", 1: "dog", 2: "bird"}
print(label_map[1])                      # "dog"

# iterate over a dict
for key, name in label_map.items():
    print(key, "→", name)

Functions

A function packages logic you reuse. In ML you'll write functions for things like preprocessing, scoring, and math operations such as the mean squared error.

def mse(predictions, targets):
    """Mean squared error: average of (pred − target)²."""
    total = 0.0
    for p, t in zip(predictions, targets):
        total += (p - t) ** 2
    return total / len(predictions)

print(mse([2.0, 3.0], [2.5, 2.0]))   # 0.625

Note: (p - t) ** 2 is Python's way to square a value — ** is the exponent operator, never ^ (that means something else in Python).

Comprehensions

A comprehension builds a new list (or dict) in one compact line — the Pythonic replacement for a simple loop. You'll see these everywhere in ML code.

# square each number
nums = [1, 2, 3, 4]
squares = [n ** 2 for n in nums]          # [1, 4, 9, 16]

# keep only the even ones
evens = [n for n in nums if n % 2 == 0]   # [2, 4]

# dict comprehension: number -> its square
sq_map = {n: n ** 2 for n in nums}        # {1: 1, 2: 4, 3: 9, 4: 16}
print(squares, evens, sq_map)
Why it matters: Comprehensions are concise and fast. But for real numeric work you'll reach for NumPy, which does the same thing across millions of values at once — without any Python loop.

3. NumPy — fast arrays & broadcasting

The foundation of scientific Python. Everything numeric in ML sits on top of NumPy arrays.

Arrays vs. lists

A NumPy array (ndarray) holds numbers in a tight block of memory and runs math in optimized C. A Python list of a million numbers is slow to add up; a NumPy array does it in one vectorized operation.

import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

# vectorized: no loop needed, whole arrays at once
print(a + b)        # [11 22 33 44]
print(a * 2)        # [2 4 6 8]
print(a.mean())     # 2.5
print(a @ b)        # dot product: 1*10 + 2*20 + 3*30 + 4*40 = 300
Vectorization means applying an operation to a whole array at once instead of looping element by element. It's shorter to write and dramatically faster.

Broadcasting

Broadcasting is NumPy's rule for combining arrays of different shapes. A smaller array is "stretched" to match the larger one — without actually copying data.

matrix (3 × 2) + row (1 × 2) → row added to every row
import numpy as np

matrix = np.array([[1, 2],
                   [3, 4],
                   [5, 6]])     # shape (3, 2)

row = np.array([10, 20])        # shape (2,)

# row is broadcast across all 3 rows of the matrix
print(matrix + row)
# [[11 22]
#  [13 24]
#  [15 26]]

# normalize columns: subtract the mean of each column
print(matrix - matrix.mean(axis=0))
Why it matters: Broadcasting is how you add a bias to every neuron, scale every feature, or normalize a whole dataset in a single line — no loops, no copies.

4. Pandas — wrangling tables

If NumPy is arrays of numbers, Pandas is labeled tables — like a spreadsheet in code.

The DataFrame

A DataFrame is a 2D table with named columns and an index. It's where most ML projects begin: load a CSV, look at it, clean it, then hand the numbers to a model.

import pandas as pd

# build a DataFrame from a dict of columns
df = pd.DataFrame({
    "name":   ["Ada", "Alan", "Grace", "Linus"],
    "age":    [36, 41, 45, 24],
    "score":  [88, 72, 95, 60],
    "team":   ["A", "B", "A", "B"],
})

print(df.head())     # first rows
print(df.shape)      # (4, 4)  -> 4 rows, 4 columns
print(df.describe()) # summary stats for numeric columns

Load a CSV, select, and filter

import pandas as pd

# load a CSV file from disk (or a URL)
df = pd.read_csv("students.csv")

# select a single column (a Series) or several columns
ages = df["age"]
subset = df[["name", "score"]]

# filter rows with a boolean condition
high_scorers = df[df["score"] > 80]

# combine conditions with & (and) / | (or)
team_a_adults = df[(df["team"] == "A") & (df["age"] >= 30)]

print(high_scorers)

Note in code we use & and | (not the words and/or) to combine Pandas conditions, and each condition needs its own parentheses.

Group and aggregate

groupby splits the table into groups, applies an aggregation (mean, sum, count…) to each, then combines the results — the "split → apply → combine" pattern.

import pandas as pd

df = pd.DataFrame({
    "team":  ["A", "B", "A", "B"],
    "score": [88, 72, 95, 60],
})

# average score per team
print(df.groupby("team")["score"].mean())
# team
# A    91.5
# B    66.0

# multiple aggregations at once
print(df.groupby("team")["score"].agg(["mean", "max", "count"]))
Why it matters: Real datasets are messy tables. Pandas is how you inspect, clean, and reshape them into the tidy numeric matrix a model expects.

5. Jupyter & Colab notebooks

The interactive scratchpad where most ML exploration happens.

What is a notebook?

A notebook mixes runnable code cells with text, math, and plots in one document. You run a cell, see the output right below it, tweak, and re-run — perfect for exploring data and iterating on models.

6. Plotting with matplotlib

Seeing your data beats guessing. matplotlib is the standard plotting library.

A quick plot

A picture reveals trends, outliers, and mistakes that raw numbers hide. The basic recipe: call a plot function, label it, and show it.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 10, 100)   # 100 points from 0 to 10
y = np.sin(x)

plt.plot(x, y, label="sin(x)")
plt.xlabel("x")
plt.ylabel("y")
plt.title("A simple line plot")
plt.legend()
plt.show()          # in a notebook the figure appears inline

Common plot types: plt.plot (lines), plt.scatter (points), plt.hist (distributions), plt.bar (categories). Libraries like seaborn build on matplotlib for prettier statistical charts.

7. End-to-end: data → model

The whole workflow in miniature: load, inspect, then train a real model with scikit-learn.

The data flow

Every ML project follows the same path. Raw data comes in as a CSV, Pandas tidies it into a table, NumPy arrays feed the math, and a model (here from scikit-learn) learns from it.

Load → inspect → train (scikit-learn)

This runnable example uses the built-in Iris dataset (no download needed), inspects it with Pandas, then trains and scores a simple classifier — the complete beginner ML loop.

import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1) LOAD  -------------------------------------------------
data = load_iris(as_frame=True)
df = data.frame                     # a Pandas DataFrame
X = data.data                       # features  (150 rows × 4 columns)
y = data.target                     # labels    (0, 1, 2)

# 2) INSPECT  ----------------------------------------------
print(df.head())                    # peek at the table
print(df.shape)                     # (150, 5)
print(df["target"].value_counts())  # how many of each class

# 3) SPLIT into train / test  ------------------------------
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42)

# 4) TRAIN a simple model  ---------------------------------
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)         # learn from training data

# 5) EVALUATE  ---------------------------------------------
preds = model.predict(X_test)
print("accuracy:", accuracy_score(y_test, preds))  # ~0.97
That's a full ML pipeline. scikit-learn's .fit() / .predict() pattern is the same for dozens of models — swap LogisticRegression for a decision tree or random forest and the rest of the code is unchanged.
