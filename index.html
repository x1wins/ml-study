🤖 AI / ML Learning Path

A beginner's roadmap: everything you need to know before becoming an AI developer.

Welcome! This page is your starting point. Artificial Intelligence (AI) is about building systems that can learn and make decisions. Machine Learning (ML) is the most common way we build AI today — instead of writing rules by hand, we let the computer learn patterns from data. Work through the sections below in order.

🗺️ Suggested Learning Order

Step 1 — Learn Python

Get comfortable writing code. Practice with small scripts before touching ML.

Step 2 — Brush up on Math

You don't need a PhD. Focus on intuition for vectors, gradients, and probability.
→ Math Foundations guide

Step 3 — Classic ML with scikit-learn

Build your first model: predict house prices or classify flowers with scikit-learn.

Step 4 — Deep Learning

Move to PyTorch or TensorFlow. Train a neural network on images.
→ Neural Networks · CNNs · RNNs/LSTMs · Transformers

Step 5 — Work with LLMs

Apply large language models to real tasks. Climb the ladder only as far as you need: Prompting → RAG → Fine-tuning.
→ Prompt Engineering · RAG · Fine-Tuning

Step 6 — Build a Project

Apply what you learned end-to-end. A finished project teaches more than 10 tutorials.

💡 Your First Model (Concept)

A minimal example using scikit-learn:

from sklearn.linear_model import LinearRegression

# X = input data, y = answers we want to predict
model = LinearRegression()
model.fit(X, y)          # learn from data
prediction = model.predict(X_new)  # make a guess
