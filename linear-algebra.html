1. Scalars, Vectors, Matrices & Tensors

Four names for numbers arranged in 0, 1, 2, or more dimensions.

The four building blocks

NameDimensionsExampleShape
Scalar0-D (a single number)3.14()
Vector1-D (a list)[2, 5, 1](3,)
Matrix2-D (a table)rows & columns of numbers(rows, cols)
Tensor3-D or morean RGB image(H, W, 3)
Why it matters: An RGB image of height H and width W is a tensor of shape H × W × 3 — three stacked matrices, one each for red, green, and blue. A batch of 32 such images is a 4-D tensor of shape 32 × H × W × 3. Shapes are the language you use to reason about data flowing through a model.

Seeing the shapes

Shapes in code

import numpy as np

scalar = np.array(3.14)             # shape ()
vector = np.array([2, 5, 1])        # shape (3,)
matrix = np.array([[1, 2],
                   [3, 4],
                   [5, 6]])         # shape (3, 2)
image  = np.zeros((128, 128, 3))    # an RGB image: H x W x 3

print(scalar.shape)   # ()
print(vector.shape)   # (3,)
print(matrix.shape)   # (3, 2)
print(image.shape)    # (128, 128, 3)

2. Vector Operations & the Dot Product

Add them, scale them, and — most important — take their dot product.

Addition and scaling

You add two vectors element by element, and you scale a vector by multiplying every element by the same number.

a + b = [a1+b1, a2+b2, …]  ·  c a = [c·a1, c·a2, …]
import numpy as np

a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 0.0, -1.0])

print(a + b)     # [5. 2. 2.]  element-wise add
print(2.5 * a)   # [2.5 5.  7.5]  scale every element

The dot product

The dot product multiplies matching elements and sums the results into a single number:

a · b = Σi ai bi = a1b1 + a2b2 + … + anbn

Geometrically the dot product equals |a| × |b| × cosθ, where θ is the angle between the vectors. So it measures how much two vectors point in the same direction:

  • Large positive → the vectors point the same way (very similar)
  • Zero → the vectors are perpendicular (unrelated)
  • Negative → the vectors point in opposite directions
Why it matters: The dot product is the workhorse of ML. It powers similarity between embeddings, the attention scores inside transformers, and the weighted sum every neuron computes. If two word or image embeddings have a large dot product, the model treats them as related. 
import numpy as np

a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 0.0, -1.0])

# dot product = sum of element-wise products
dot = np.dot(a, b)              # 1*4 + 2*0 + 3*(-1) = 1.0
print(dot)                      # 1.0

# same thing spelled out
print(np.sum(a * b))            # 1.0

3. Matrix Multiplication

A matrix multiply is just many dot products bundled together — and it is the core of every neural-network layer.

The rule

To multiply matrix A (shape m × n) by matrix B (shape n × p), the inner dimensions must match. Each output entry is the dot product of a row of A with a column of B.

(m × n) · (n × p) → (m × p)

Worked example: a 2×2 matrix times a 2×1 vector

This is exactly what one neural-network layer does. Take:

W = [[1, 2],  [3, 4]]  ·  x = [5, 6]

Multiply each row of W by the vector x as a dot product:

  • Row 1: (1 × 5) + (2 × 6) = 5 + 12 = 17
  • Row 2: (3 × 5) + (4 × 6) = 15 + 24 = 39
W·x = [17, 39]T

Why this IS a neural-network layer

A layer takes an input vector x, multiplies it by a weight matrix W, and adds a bias vector b:

output = W·x + b

Each row of W is one neuron's weights; the matrix multiply computes every neuron's weighted sum in a single operation. Stack layers and add activations, and you have a deep network. GPUs are fast precisely because they do these matrix multiplies in parallel.

import numpy as np

W = np.array([[1.0, 2.0],
              [3.0, 4.0]])     # shape (2, 2)
x = np.array([5.0, 6.0])       # shape (2,)
b = np.array([0.5, -1.0])      # bias, one per output neuron

# the @ operator is matrix multiplication in numpy
out = W @ x + b                # [17.5, 38.0]
print(out)                     # [17.5 38. ]

# without the bias (the pure matmul from the diagram)
print(W @ x)                   # [17. 39.]
Why it matters: Every dense layer, convolution, and attention block in modern AI reduces to W·x + b style matrix multiplies. Understanding this one line explains most of what a neural network computes.

4. Transpose, Identity & Inverse

Three matrix operations you will meet constantly.

Transpose — flip rows and columns

The transpose AT turns rows into columns. An entry at position (row i, col j) moves to (row j, col i). It is used constantly to line up shapes so a matrix multiply is valid.

import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])   # shape (2, 3)
print(A.T)                  # shape (3, 2)
# [[1 4]
#  [2 5]
#  [3 6]]

Identity — the "1" of matrices

The identity matrix I has 1s on the diagonal and 0s elsewhere. Multiplying by it changes nothing: I·x = x, just like multiplying a number by 1.

I = [[1, 0], [0, 1]]  →  I·x = x
import numpy as np

I = np.eye(3)          # 3x3 identity
x = np.array([7, 8, 9])
print(I @ x)           # [7. 8. 9.]  unchanged

Inverse — the "undo" matrix

The inverse A−1 undoes what A does: A·A−1 = I. It is the matrix version of dividing. Not every matrix has one (only square, non-degenerate matrices do), and computing it is expensive — which is why deep learning avoids explicit inverses and uses gradient descent instead.

import numpy as np

A = np.array([[4.0, 7.0],
              [2.0, 6.0]])
A_inv = np.linalg.inv(A)
print(A @ A_inv)       # approximately the identity:
# [[1. 0.]
#  [0. 1.]]

5. Norms — Length & Distance

A norm measures the "size" or "length" of a vector — a single number.

L2 norm (Euclidean length)

The L2 norm is the straight-line length of a vector: square each element, sum them, take the square root. It is the Pythagorean theorem generalized to any number of dimensions.

‖x‖2 = √(Σi xi2) = √(x12 + x22 + … + xn2)

L1 norm (Manhattan distance)

The L1 norm adds up the absolute values — the distance you would walk along a city grid.

‖x‖1 = Σi |xi| = |x1| + |x2| + … + |xn|
Why it matters: Norms give distance and magnitude. The distance between two embeddings ‖a − b‖ tells you how different they are. Norms also drive regularization (L2 = weight decay, L1 = sparsity) that keeps models from overfitting.
NormFormulaMeaningML use
L2√(Σ xi2)straight-line lengthdistances, weight decay
L1Σ |xi|grid-walk lengthsparsity (drives weights to 0)
import numpy as np

x = np.array([3.0, 4.0])

# L2 norm = sqrt(3^2 + 4^2) = sqrt(25) = 5.0
l2 = np.sqrt(np.sum(x ** 2))
print(l2)                       # 5.0
print(np.linalg.norm(x))        # 5.0  (built-in, same result)

# L1 norm = |3| + |4| = 7.0
l1 = np.sum(np.abs(x))
print(l1)                       # 7.0
print(np.linalg.norm(x, ord=1)) # 7.0

# distance between two vectors = norm of their difference
a = np.array([1.0, 2.0])
b = np.array([4.0, 6.0])
print(np.linalg.norm(a - b))    # 5.0

6. Eigenvectors & PCA

The intuition behind finding the "main directions" in your data.

Eigenvectors & eigenvalues (the intuition)

When a matrix transforms space, most vectors get rotated and stretched. An eigenvector is a special direction that only gets stretched, never rotated. Its eigenvalue is how much it stretches.

A·v = λ·v   (v stays on its line, scaled by λ)
Why it matters: Eigenvectors reveal the natural axes of a dataset. The eigenvector with the biggest eigenvalue is the direction along which your data varies the most — the most "informative" direction.

PCA — keep the directions that matter

Principal Component Analysis (PCA) finds the directions of greatest variance in your data (the top eigenvectors of its covariance matrix), then projects the data onto just a few of them. You throw away the low-variance directions, shrinking many features down to a few while keeping most of the information.

Projecting the 2-D cloud onto just PC1 keeps most of the spread while reducing the data from two numbers per point to one — that is dimensionality reduction.

import numpy as np

# 5 examples, 2 features, stretched along a diagonal
X = np.array([[2.0, 2.4],
              [0.5, 0.7],
              [2.2, 2.9],
              [1.9, 2.2],
              [3.1, 3.0]])

# 1) center the data (PCA needs zero mean)
X_centered = X - X.mean(axis=0)

# 2) covariance matrix (features x features)
cov = np.cov(X_centered, rowvar=False)

# 3) eigen-decomposition: eigenvectors are the principal directions
eigvals, eigvecs = np.linalg.eigh(cov)

# 4) the eigenvector with the largest eigenvalue = PC1
pc1 = eigvecs[:, np.argmax(eigvals)]
print("PC1 direction:", pc1)

# 5) project the data onto PC1 -> 2 features become 1
reduced = X_centered @ pc1
print("reduced (1-D):", reduced)
Why it matters: PCA compresses high-dimensional data (thousands of features) into a handful of meaningful directions — speeding up training, removing noise, and making data visualizable in 2-D or 3-D.

7. How ML Actually Uses This

From linear algebra to real models

ConceptWhere it shows up in ML
Matrix (rows × cols)A dataset: rows = examples, columns = features
VectorAn embedding — a word, image, or user as a list of numbers
Dot productSimilarity between embeddings; attention scores in transformers
Matrix multiplyA neural-network layer: output = W·x + b
NormDistance between points; regularization to prevent overfitting
Eigenvectors / PCADimensionality reduction, denoising, visualization
The through-line: data becomes vectors and matrices, the model transforms them with matrix multiplies, dot products measure similarity, and norms measure distance. That is the linear-algebra skeleton underneath nearly every AI system.

Quick recap

  • Scalar / vector / matrix / tensor — numbers in 0, 1, 2, or more dimensions
  • Dot product — Σ aibi, measures similarity / projection
  • Matrix multiply — many dot products; the core of every layer (W·x + b)
  • Transpose / identity / inverse — flip, the "1", and the "undo" of matrices
  • Norms — L2 = √Σx2 length, L1 = Σ|x| grid-distance
  • Eigenvectors / PCA — directions of greatest variance for dimensionality reduction
